# **Processing Grant Applications**

This guide covers how to review and process grant applications from clubs and individuals.

---



## **Policy vs System**



**Important distinction:**


| Type | Who Decides | Examples |
| ---------- | ----------------------- | ------------------------------------------------------------------ |
| **Policy** | TUSA internal direction | Funding limits, what expenses are approvable, approval criteria |
| **System** | Technical requirements | Where to find applications, required documents, how approvals work |


This documentation covers **system requirements only**. Funding decisions are based on internal policy – refer to your manager or grants policy documents.

---



## **Types of Grant Applications**




| Type | Who Applies | What It’s For |
| -------------------- | -------------------------------- | ------------------------------------------- |
| **Club Grant** | Club president on behalf of club | Club activities, equipment, events |
| **Individual Grant** | Any student | Personal development, conference attendance |
| **Startup Grant** | Automatic | Created when new club is affiliated |
| **Event Grant** | Club president | Funding requested with event application |

## **Finding Grant Applications**



&nbsp;

### **Your Workflow Inbox**



**Where:** Profile avatar → Profile → Workflow Inbox tab  
**Direct URL:** `/my/workflow-inbox/`

Grant applications assigned to you appear here. You need the grants admin role to see these.



### **TUSA Internal Group**



**Where:** `/clubs/clubs-index/tusa-internal/` → **Grants** tab


| Sub-tab | What’s Here |
| ------------------------------ | ---------------------------------------------- |
| **Applications** | All grant applications |
| **Current Grants** | Active grant types available |
| **Grant Prerequisites + Caps** | Requirements and spending limits by grant type |

## **Processing a Club Grant**



&nbsp;

### **Step 1: Review the Application**



Open the application from your workflow inbox or the Grants tab.

**Check the basics:**


| Item | What to Look For |
| ------------------------ | ---------------------------------------- |
| **Club name** | Valid affiliated club |
| **Grant type** | Appropriate type selected |
| **Amount requested** | Within limits for this grant type |
| **Purpose** | Clear explanation of what funding is for |
| **Supporting documents** | Required docs attached |


### **Step 2: Check Documents**



Club grant applications can include several types of documents:


| Document Type | Where It Comes From |
| ------------------------- | ---------------------------------------------------- |
| **New uploads** | Documents uploaded specifically for this application |
| **Existing club docs** | Selected from the club’s document library |
| **Affiliation documents** | Constitution, etc. automatically included |


**Verify:**

- Documents are readable and relevant
- Quotes/invoices support the amount requested
- Required documentation is present for this grant type



### **Step 3: Check Requirements and Caps**



The grant type determines what’s required and spending limits.

**Where to check:** TUSA Internal → Grants → Grant Prerequisites + Caps


| Check | What to Look For |
| ------------------- | ---------------------------------------------------------------- |
| **Requirements** | Has the club provided everything needed for this grant type? |
| **Caps** | Is the amount requested within the limits? |
| **Previous grants** | Has the club already received similar funding? (policy decision) |


### **Step 4: Approve, Adjust, or Return**



**If everything looks good:**

- Approve the application
- Enter the approved amount (may be less than requested)

**If issues need fixing:**

- Return for amendment with notes on what’s needed

**If declined:**

- Reject with reason (per policy guidelines)



### **What Happens After Approval**




| Item | What Happens |
| ------------------ | ----------------------------------------- |
| **Notification** | Club receives approval notification |
| **PDF generated** | Summary document created with all details |
| **Status updated** | Application marked as approved in system |

## **Processing an Individual Grant**



Individual grants work similarly but with some differences.



### **Key Differences from Club Grants**




| Club Grant | Individual Grant |
| ------------------------- | ---------------------- |
| Applied by club president | Applied by any student |
| Club documents available | Only their own uploads |
| Linked to a club | Not linked to any club |


### **What to Check**




| Item | What to Look For |
| ----------------- | ----------------------------- |
| **Applicant** | Valid TUSA member |
| **Grant type** | Appropriate for individuals |
| **Purpose** | Clear explanation |
| **Documentation** | Supporting documents uploaded |
| **Amount** | Within individual limits |


### **Documents**



Individual applicants upload their own documents directly – there are no “existing club documents” to select from.

---



## **Startup Grants**



Startup grants are **automatically created** when a new club is affiliated.



### **How They Appear**



- New club application is approved
- System automatically creates a startup grant application
- Grant appears in your workflow inbox / Grants tab
- Process like any other club grant



### **What’s Different**



- Documents are pulled from the affiliation (constitution, etc.)
- Club details are pre-filled
- Just verify and approve the startup amount

---



## **Event Grants**



When clubs submit event applications, they can request funding at the same time.



### **How They Appear**



- Club submits event/risk assessment with funding request
- Event grant is automatically created
- Appears in Grants tab linked to the event
- Process like other club grants



### **What’s Different**



- Documents come from the event application
- Grant is linked to a specific event
- Event approval and grant approval are separate processes

## **Checking the Club’s Document Library**



When reviewing club grants, you may want to check what documents the club has on file.

**Where to look:**


| View | Where | What You See |
| ------------------------- | ------------------------------ | -------------------------- |
| All clubs’ documents | TUSA Internal → Documents tab | Every club’s documents |
| Specific club’s documents | Club dashboard → Documents tab | Just that club’s documents |


This helps you verify:

- Club has up-to-date constitution
- Previous grant documentation
- Any other relevant records

## **Common Issues**



&nbsp;

### **“I can’t see the application”**



**Check:**

- Is it assigned to you? Check workflow inbox
- Do you have grants admin role?
- Look in TUSA Internal → Grants tab



### **“Documents are missing”**



**If new uploads missing:**

- Ask applicant to resubmit

**If club documents missing:**

- Check TUSA Internal → Documents
- Club may need to upload to their library first



### **“Requirements/caps didn’t show for applicant”**



If the applicant says they couldn’t see requirements:

- This is a system display issue
- Check TUSA Internal → Grants → Grant Prerequisites + Caps
- Requirements should be configured for that grant type
- Contact a developer if grant type is misconfigured



### **“Amount exceeds the cap”**



**Options:**

- Approve partial amount (up to the cap)
- Return for amendment to reduce request
- Escalate if policy allows exceptions



### **“Club has already received this grant type”**



**This is a policy decision:**

- Some grants are one-time only
- Some have annual limits
- Check with your manager or policy documents

## **Processing Grant Claims**



When a club has an approved grant, they submit a separate claim form to receive the funds. Claims come through your workflow inbox just like grant applications.



### **Claim Workflow**



- **Club submits a claim** — They select the approved grant, enter the amount they’re claiming, and attach any supporting documents (receipts, invoices, etc.)
- **Admin assignment** — The claim is assigned to a grants administrator
- **Review and decision** — You review the claim and approve or reject it
- **Notification** — The applicant receives an email with the outcome



### **Reviewing a Claim**




| Item | What to Check |
| ------------------------ | --------------------------------------------------------------------- |
| **Grant** | Is this against a valid, approved grant? |
| **Amount** | Is the claim within the remaining balance? |
| **Previously claimed** | The system shows how much has already been claimed against this grant |
| **Supporting documents** | Receipts, invoices, or proof of expenditure |
| **Bank details** | Club has an approved Bank Signatory Form on file |


The system automatically calculates how much has already been claimed against a grant. If someone tries to claim more than the remaining balance, the system will block the submission.



### **Approving or Rejecting a Claim**



When you approve or reject a claim, **any notes you write are included in the notification email sent to the applicant**. This is true for both approvals and rejections.

**Best practice:**

- Always write clear, professional notes — the applicant will see them
- For approvals: confirm what was approved and any conditions
- For rejections: explain why and what (if anything) the club can do next
- Keep the tone helpful and constructive



### **Partial Claims**



Clubs can submit multiple claims against the same grant, as long as the total doesn’t exceed the approved amount. For example, a club with $500 approved might claim $200 now and $300 later.
