# **Managing TUSA Merch Store Products**

The TUSA Merch Store (Vendor 14) is the main store for TUSA-branded merchandise, general supplies, and items sold directly by the union.

---



## **Who Can Manage This**



- **Site administrators** — full access via the site admin
- **TUSA Store staff** — users with the `tusashopadd` role, via the Store Manager (frontend)

---



## **Accessing via Store Manager (Frontend)**



If you have the `tusashopadd` role:

- Go to your **Profile**
- Click the **Store Manager** tab
- You should see “TUSA Store” at the top — confirm you are in the right store
- Click **Products** to see existing products or add new ones

---



## **Accessing via the Site Admin (Administrators)**



- Go to **Products** in the site admin sidebar
- Use the vendor filter or search to find TUSA Store products
- When creating a new product, make sure the **Vendor** field is set to **TUSA Store** (Vendor 14)

---



## **Adding Products**



- Click **Add New Product** (frontend) or **Products > Add New** (site admin)
- Enter product details: name, price, description, image
- Select the appropriate category:

– **Merchandise** — physical items (shirts, hoodies, stickers)  
– **Supplies** — consumables, stationery

- Set shipping if it is a physical product
- Publish

---



## **Important Notes**



- The TUSA Store is the union’s own store — it is not a club store
- Products here appear on the main TUSA store page
- Revenue goes to TUSA, not to individual clubs
- Only use existing product categories
