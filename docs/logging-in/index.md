# **Logging In**

This guide explains how to log in to the TUSA website — both for staff and for  
members.



## **Staff: how to log in**



**Staff log in through the WordPress login screen, using this web address:**



```
https://tusa-dev.its.utas.edu.au/wp-admin/?brx_use_wp_login=1

```



Copy that address exactly — including the slash before the question mark — and  
paste it into your browser. Bookmark it so it is always easy to find. It opens the  
standard WordPress login box where you enter your username and password.

After you log in you land in the WordPress dashboard, where you do your TUSA work.



### **Why staff have their own login address**



The website has a separate, branded login page for members (see below). **Staff**  
**should not use the members’ login page.** Once extra login security (a code from  
your phone) is switched on for staff accounts, the members’ page cannot ask for  
that code — so it would keep sending you back to the start without ever letting you  
in. The staff address above avoids that completely.

**In short:** members use the branded login page; staff use the address above.



## **Members: how members log in**



Members log in on the website’s own branded login page. The account icon in the  
site header takes them there.

That page has three tabs:

- **Login** — for members who already have an account.
- **Reset Password** — for members who have forgotten their password.
- **Create your account** — for new members to sign up.

Members fill in the relevant tab and continue from there. They never need the staff  
login address.



## **New members: no confirmation email**



When someone creates an account on the **Create your account** tab, they’re signed  
up and logged in **straight away** — there’s no confirmation or activation email to  
wait for. So if a new member says they’re waiting on a verification email, there  
isn’t one; they should already be logged in, or can log in on the **Login** tab.



## **If you get stuck**



- **The login box won’t appear / it keeps reloading:** make sure you used the full

staff address above, with the slash before the question mark.

- **You’re a staff member and the login keeps sending you in circles:** you are

probably on the members’ login page by mistake. Use the staff address above  
instead.

- **A member forgot their password:** they use the **Reset Password** tab on the

branded login page.

- **A new member “can’t log in” and is looking for a confirmation email:** there is

no confirmation email (see above). Check they’re using the **same email address**  
they signed up with, and if needed have them use the **Reset Password** tab to set  
a fresh password.
